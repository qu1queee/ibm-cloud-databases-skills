# ibm-cloud-databases-skills

Agent Skills for IBM Cloud Databases Gen 2, in the [Agent Skills](https://agentskills.io/specification) format. The directory name under `skills/` matches the `name` in `SKILL.md`.

| Skill | Reach for it |
| --- | --- |
| `cloud-databases-gen2` | Gen 2 control plane shared by the engine skills |
| `postgresql` | Databases for PostgreSQL. Its first step applies `cloud-databases-gen2` |
